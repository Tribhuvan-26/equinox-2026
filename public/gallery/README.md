# Previous Event Gallery Uploads

Drop your event photos here!

### File Naming Convention:
You can simply name your photos:
- `photo-1.jpg` (or `.png` / `.webp`)
- `photo-2.jpg`
- `photo-3.jpg`
- `photo-4.jpg`
- `photo-5.jpg`
- `photo-6.jpg`
- `photo-7.jpg`
- `photo-8.jpg`
- `photo-9.jpg`
- `photo-10.jpg`
- `photo-11.jpg`
- `photo-12.jpg`
...and so on!

The gallery will automatically load and display them across both:
1. The **Gallery Section** directly above "Contact Us" on the Homepage (`/`)
2. The dedicated **Gallery Page** (`/gallery`)

Whenever you add or replace photos, they will show up instantly.
